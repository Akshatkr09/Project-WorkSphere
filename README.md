# WorkSphere

Multi-Tenant Project Management & Workflow Automation Platform.

## Milestone 2.1 — Database foundation
This update adds the initial PostgreSQL/Prisma domain schema and database setup guide. Follow `docs/development/database.md`.

Stack: Next.js + TypeScript, Express + TypeScript, FastAPI, PostgreSQL, Prisma, and Redis for later job workflows.

Gemini may be used in a later AI-specific feature. No AI API key is required for this milestone.
