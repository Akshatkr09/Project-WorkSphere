# Assessment evidence index

Each assessment folder should contain:
- `README.md`: objective, design, setup, API/UI usage, assumptions and limitations.
- `evidence/`: screenshots, sanitized logs, test reports or recording link.
- tests committed alongside the feature; generated output must identify commit SHA and command.

Use `docs/PROJECT-DELIVERY-PLAN.md` as the cross-assessment status source. Do not mark work complete based solely on a mock screen or a health endpoint.

## Evidence naming
`Axx-<topic>-<YYYYMMDD>.<ext>` (for example `A03-migration-output-20261128.txt`). Never include credentials, real personal data, or production secrets.
